## 1. OSI & TCP/IP Models

### OSI Model Layers Reviewed
- **Layer 1 – Physical:** Cables, signals, connectors
- **Layer 2 – Data Link:** MAC addresses, switches, VLANs
- **Layer 3 – Network:** IP addressing, routing, default gateways
- **Layer 4 – Transport:** TCP vs UDP, ports
- **Layer 5 – Session:** Session establishment, NetBIOS session
- **Layer 6 – Presentation:** Encryption, compression
- **Layer 7 – Application:** DNS, DHCP, HTTP, FTP, etc.

### Key Associations
- **QoS:** Layer 2–4 (primarily L2/L3 in practice)
- **IDS / IPS:** Network-based security controls
- **VPN:** Encrypted tunnels (L3/L4)
- **Default Gateway:** Router used to reach non-local networks

## 4. Wireless Networking (802.11)

### Wi-Fi Standards
| Standard | Bands | Key Features |
|--------|-------|--------------|
| 802.11a | 5 GHz | Less interference, shorter range |
| 802.11b | 2.4 GHz | Longer range, more interference |
| 802.11g | 2.4 GHz | Combines a/b benefits |
| 802.11n (Wi-Fi 4) | 2.4 & 5 GHz | MIMO |
| 802.11ac (Wi-Fi 5) | 5 GHz | Wider channels |
| **802.11ax (Wi-Fi 6)** | **2.4 / 5 / 6 GHz** | **OFDMA, MU-MIMO** |

### Key Concepts
- **OFDMA:** Divides channels to reduce contention
- **MU-MIMO:** Multiple users simultaneously
- **6 GHz:** Wi-Fi 6E
- **WPA3:** Modern wireless security

## 9. Subnetting Foundations

### Core Understanding
- Subnetting = grouping IPs into ranges (blocks)
- **Block size = 2^(32 − CIDR)**

### Specificity Rule
- Smaller subnet = **more specific**
- Larger subnet = **less specific**

### Mental Method (Key Breakthrough)
- Find the **largest multiple of the block size that is ≤ target IP**
- That multiple = **Network ID**
